# Credit Risk Intelligence Dashboard

## 📊 Power BI Project

A Power BI project analyzing credit risk, loan exposure, defaults, and expected losses across 5K customers.

<img width="606" height="358" alt="image" src="https://github.com/user-attachments/assets/993e7428-df11-4b77-91b8-cb0749d4d5fe" />


### 🎯 Objectives
- Analyze loan portfolio exposure
- Identify default risk drivers
- Segment customers by risk
- Identify potential credit losses
- Provide business recommendations

### 🛠️ Tools
- Power BI
- DAX
- Excel
- Data Analysis & Visualization

### 📌 Key Insights
- Total Loan Exposure: **127M**
- Default Rate: **22.56%**
- High-Risk Exposure: **43M**
- High-Risk Expected Loss: **9.26M**
- Grade E has the highest default rate.
- Default risk decreases as credit score improves.

### 📑 Dashboard Pages
1. Executive Risk Overview
2. Risk Drivers
3. Risk Segmentation
4. Key Risk Insights & Recommendations

### 💡 Business Recommendations
- Strengthen credit screening
- Control high-risk exposure
- Use risk-based lending
- Continuously monitor high-risk borrowers
